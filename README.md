# AI-Career-Mentor
To run this project firstly run 
1. git clone https://github.com/adidound/AI-Career-Mentor.git in your VS code terminal 
2. Once the repo is cloned execute cd AI-Career-Mentor to ensure you're in the correct folder
3. Once you're in the correct folder execute this command to create a virtual environment python -m venv venv
4. Use this command to activate your virtual environment venv\Scripts\activate
5. pip install streamlit pandas to install the required dependencies. 
6. streamlit run app.py to run this project.
